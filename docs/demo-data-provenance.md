# 공개 데모 데이터의 출처와 검증 한계

`data/demo/patients.seed.json`의 인물·생년월일·방문 시점·연락 상태는 가상 데모용으로 준비된 값입니다. 다만 진료 시나리오의 일부는 과거 제공된 모의 진료와 검수 자료를 바탕으로 작성됐으며, 전부 새로 독립 생성한 데이터라고 설명하지 않습니다.

이번 공개 파일 정리에서는 원음·전사·대본·검수 원문을 공개 저장소에서 제외했습니다. 해당 비공개 자료를 참조하던 50개 근거 객체의 `source_id`와 직접 인용 `quote`는 `null`로 가렸습니다. 원래의 `kind`와 `origin`은 역사적 작성 경위를 보존하며, 현재 공개 사본에서 원문 대조가 가능하다는 뜻이 아닙니다. 새로운 합성 원문을 만들어 기존 출처로 둔갑시키지 않았습니다.

`scenario_inputs.source_documents`는 이 공개 상태 설명을 가리킵니다. `video1`, `video2`, `revisit_script`는 기존 시나리오 계약을 유지하기 위한 식별자일 뿐, 녹음·대본 파일이 포함됐거나 새로 검증됐다는 뜻이 아닙니다.

JSON Schema·ID 관계·방문 상태·시간 순서·가상 사진 해시 등 공개 파일만으로 검증할 수 있는 조건은 기존 검증기로 확인합니다. 가려진 근거의 임상 내용과 원문 일치 여부는 그 검사로 확인되지 않습니다. 출처가 없는 근거를 확인 완료로 표시하거나 실제 환자 기록에 재사용하지 마세요.

시나리오 전체를 재배포 가능한 독립 합성 예제로 교체하거나 원래 자료의 허락을 확인하는 일은 [유지관리 계획](maintenance.md)과 [외부 자료 고지](../THIRD_PARTY_NOTICES.md)의 미완료 항목입니다. 이번 문서는 그 권리 확인을 대신하지 않습니다.
