# 전신 혈자리 선택 연결

2026년 10월 9일. 전신 후보 선택을 로컬 코드에 연결했다. 푸시·운영 배포는 이 작업에서 수행하지 않았다.

## 동작

- 기존 16개 발목 루틴과 별도로 원본 361개 정규 경혈을 모두 선택 목록에 연결한다.
- 원본의 25개 세부 부위를 화면의 큰 부위와 연결한다. 얼굴·팔꿈치·손목·엉치 등은 세부 부위로 직접 선택할 수도 있다. 기존 인체 영역 판정과 남성·여성·과거 도해의 좌표는 변경하지 않는다.
- 체크/터치 후에는 해당 부위의 후보를 열고 전신 검색으로 넓힐 수 있다. 한글·한자·코드·경맥·부위 이름으로 검색하며 복류·LV/LR·SJ/TB/TE 별칭을 처리한다.
- ‘목록에서 선택’은 전신 361개 목록을 연다. 세로 화면의 해당 버튼 노출 정책은 메인 레이아웃을 그대로 따르며, 인체 부위 선택 후에도 전신 검색을 사용할 수 있다.
- 검색어·부위 필터를 바꿔도 이미 선택한 항목은 유지한다. 저장 시 각 항목의 실제 분류를 사용해 다른 부위의 코드가 초기 팝업 부위로 잘못 저장되지 않게 한다.
- 정중선 경혈은 정중선으로 저장한다. 양측 경혈은 좌측·우측·양측을 확인해야 추가할 수 있다. 시술 선택은 실제 시행 확인과 별도다.
- 수동 목록을 열었다는 이유로 인체 가운데에 가짜 부위 표시를 그리거나 해당 위치로 확대하지 않는다.

## 자료와 범위

원본은 `data/acupoints/경혈_361_위치좌표.json`이며, 앱용 최소 필드는 `data/acupoints/tablet-catalog.json`으로 추출한다. 전체 위치 설명 원문과 원본 x/y는 브라우저 선택 자료에 넣지 않는다. 항목별 위치 참고 링크와 원본의 검수 상태를 보존한다. 출처는 `public/demo/acupoints/ATTRIBUTION.html`에 표시한다.

전신 검수 자료의 화면 표시 후보와 임상 위치 승인은 별개다. 이번 변경은 3D 인체 위에 정밀 점을 배치하거나 검수 상태를 승인으로 바꾸지 않는다.

```sh
python3 scripts/build_tablet_acupoint_catalog.py --check
npx vitest run src/lib/tablet/acupoint-catalog.test.ts src/lib/tablet/geometry.test.ts
npx tsx --test src/lib/server/acupoint-catalog.test.ts
```

## 검증

- 관련 단위 검사 13개, 저장 경계 검사 1개, TypeScript 통과.
- 별도 로컬 스냅샷의 Next.js production build 통과. 원본 작업 디렉터리의 빌드·서버·환경 설정을 변경하지 않았다.
- 별도 로컬 저장소의 브라우저 검사 2개 통과: 세로 부위 선택→전신 검색→합곡 좌측/백회 정중선 저장→약침 신수 우측 저장→재로드; 가로 수동 전신 목록·한자 검색·가짜 위치 표시 없음.
- 운영 DB·API 키·실제 음성 입력은 사용하지 않았다.

메인 작업에서 수정 중이던 `RegionPicker`의 `onZoom`/`modal` 지원과 세로·여성 도해 코드는 보존했다. `TabletWorkspace`에는 수동 목록의 `selectionSource`, 가짜 표시·확대 방지, 부위 혼합 선택에 맞춘 저장 알림만 좁게 변경했다.
