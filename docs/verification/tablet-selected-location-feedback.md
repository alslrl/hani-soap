# iPad 선택 경혈 표시 검증

부위 선택 → 경혈 선택 → 추가 후, 현재 시술의 선택 위치를 인체와 목록에서 바로 확인한다.

- 기존 회색 참고점 위에 진회색 번호 점을 표시하고, 인체 아래에 같은 번호의 혈명·코드·환자 기준 좌우를 표시한다. 점·라벨·선택 목록은 모두 무채색이며 선택 상태는 명도와 테두리로 구분한다.
- 추가한 첫 위치의 이름을 점 옆에 표시한다. 목록의 다른 위치를 누르면 그 이름을 표시하며, 필요하면 앞면/뒷면을 전환한다.
- 양측 선택은 같은 번호의 점을 좌우에 각각 표시한다. 정중선은 한 점으로 표시한다.
- 침·도침·약침·뜸·부항은 해당 시술의 선택만 표시한다. 기록에서 삭제하면 점과 목록에서도 제거한다.
- 선택 기록으로 표시를 계산하므로 추가 직후와 저장 후 새로고침 모두 동일한 경혈 정보를 사용한다. 표시 좌표나 번호는 저장 데이터에 새로 추가하지 않는다.

## 표시 좌표의 범위

남성/여성 도해별 기존 `acupoint-reference-overlay.json`의 **대략적인 표시 좌표**를 사용한다. 이 좌표는 임상 위치 검수가 완료된 좌표가 아니다. 앞·뒷면 표시가 없는 측면/숨은 표면의 경혈, 아시혈/압통점은 점을 만들어내지 않고 목록에 표시 사유를 안내한다. 해당 항목을 누르면 위치 설명을 확인할 기록 패널이 열린다.

기존 도해에 연결된 위치는 현재 도해로 투영하지 않는다. 이전 도해의 원본 필기와 읽기 전용 동작을 유지한다. 표시 점은 포인터 입력, 지우개, 필기 이미지 추출에 포함되지 않는다. 선택과 실제 시행 확인은 기존대로 분리한다.

## 확인 결과 (2026-10-09)

- TypeScript 검사 통과, 관련 단위 테스트 24개 통과. 남녀 좌표, 좌우 반전, 양측, 정중선, 뒷면, 표시 없는 경혈, 이전 도해와 입력/지우개 회귀를 확인했다.
- 별도 임시 복사본의 프로덕션 빌드 통과. API 키와 클라우드 저장소를 연결하지 않은 로컬 저장소에서 브라우저로 검증했다.
- 세로 834×1194 화면에서 여성 도해의 우측 합곡 LI4, 정중선 중완 CV12를 추가하고 점/번호/목록을 확인했다. 신수 BL23 목록을 누르면 뒷면 우측 점으로 이동했다.
- 초안 저장 후 새로고침으로 점과 선택 목록이 복원됐다. 로컬 저장 결과는 `suggested`이며 시행 확인으로 바뀌지 않았다.
- 약침으로 전환하면 침 점과 목록이 사라지고, 침으로 돌아오면 복원됐다.
- 합곡 점 위에 필기를 추가하고 지우개로 지운 뒤에도 선택 점 2개와 참고점 368개가 유지됐다.
- 측면 환도 GB30은 목록에서 표시 제한을 안내하며 기록 패널로 연결됐다. 임시 선택을 삭제한 후 기존 세 경혈을 다시 저장했다.
- 가로 1366×1024 배치와 남성 도해의 양측 합곡을 확인했다. 양측은 한 선택 항목에 같은 번호의 좌우 점 두 개로 표시됐다. 브라우저 오류 없음.
- 기존 E2E 사양에 선택 점·목록·시술 분리·새로고침 복원 assertion을 추가했다. 이번 확인은 CUA 브라우저 조작으로 수행했으며 E2E 스위트 전체 실행은 하지 않았다.

실물 iPad/Apple Pencil은 직접 검증하지 않았다. 배포 완료 여부는 실제 배포 상태와 운영 화면으로 별도 확인한다.
