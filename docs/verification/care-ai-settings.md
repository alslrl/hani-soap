# AI 안내 생성 설정 변경 검증

2026-10-09. 새 안내에서 안내 시점·기준 진료·복약 과정을 바꾸면 문안이 비어 있는데도 전체 dirty 상태가 되어 AI 생성과 빈 초안 저장이 모두 잠기던 문제를 수정했다.

설정 변경과 본문 편집을 구분한다. 선택한 설정은 AI 요청에 바로 전달하고, 요청이 수락되면 생성된 초안을 불러올 수 있도록 설정의 미저장 상태를 정리한다. 직접 편집하거나 승인 문안에서 복사한 본문은 저장 전 AI로 덮어쓰지 않는다. 생성 대기 중 본문을 편집하면 늦은 생성 결과와의 자동 연결을 해제해 저장 후에도 수기 문안이 유지된다. 요청 전송 중에는 입력을 잠가 응답으로 최근 편집이 사라지는 상황을 막는다.

검증: TypeScript·production build 및 격리 로컬 브라우저 5건 통과. 설정 3종 변경 후 요청/결과 반영, 빈 문안 저장 불필요, 늦은 AI 결과와 수기 저장 보호, 복사한 승인 문안 보호, 기존 연락 처리, 날짜별 맞춤 케어 근거를 포함한다. 브라우저의 생성 결과는 합성 응답 fixture이며 실제 메시지 발송을 수행하지 않는다.
