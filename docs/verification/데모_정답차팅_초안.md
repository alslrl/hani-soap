# 데모 정답 차팅 초안 및 검수 기록

작성일: 2026-10-09 (KST)

기존 영상 전사본과 참고 대본을 대조한 예상 출력이다. 2026-10-09 연화가 발목·야뇨 SOAP 검토 과제에 대해 '1번 soap는 다 맞아'라고 확인하여 두 사례의 S/O/A/P를 의료진 검토 완료된 비교 기준으로 사용한다. 아래 '연화 확인'에는 별도로 대조한 영상 수치·표현을 기록한다. SOAP 검수 완료와 전체 원음·전사문 모든 구간의 최종 검수는 구분한다. 의료진이 발화한 평가·계획을 기록하는 평가용 자료로, 임상적 진단·치료의 타당성을 별도로 검증한 문서가 아니다. 공개용 환자 표시는 환자 A·B로 하고 실명·생년월일을 옮기지 않는다.

검수 상태:

- 환자 A 발목 염좌 SOAP: 연화 검수 완료 (2026-10-09).
- 환자 B 소아 야뇨 SOAP: 연화 검수 완료 (2026-10-09).
- 다음 재진 질문·그래프: 개발 참고안. 이번 SOAP 확인을 별도 질문·그래프 검수 완료로 확대하지 않는다.
- 발목 데모 혈자리: 사용자 제공 루틴의 16개 정규 혈자리와 아시혈로 선정 완료. [선정 목록](../reference/발목_데모_혈자리.md) 참고. 도해 위치·좌우 검수는 남음.

## 연화 확인

| 사례 | 확정한 내용 | 확인 근거 |
| --- | --- | --- |
| 발목 염좌 | 부종 측정값 좌 43cm, 우 45cm | 사용자가 앞선 비교 수치에 대해 '발목영상도 맞아'라고 확인 |
| 발목 염좌 | 가동범위 좌 배굴 20°·저굴 35°, 우 배굴 10°·저굴 25° | 동일 사용자 확인 |
| 소아 야뇨 | 영상에서 의료진이 말한 평가명은 '과민성 방광염' | 사용자가 해당 표현을 확인 |
| 소아 야뇨 | 한의학적 변증 문진 질문 4의 표현은 '입을 벌리고' | 사용자가 질문 위치와 표현을 확인 |

PDF와 영상 수치가 다르면 영상에서 확인한 값을 사용한다. 기존 전사본의 '과민성 방광', '이불 벌리고'는 위 검수 결과에 맞게 예상 출력에서 반영한다. 최초 전사본은 보존한다. '입을 벌리고 자거나 코를 골지는 않나요?'는 질문이고, 입을 벌리고 잔다고 답한 사실로 변환하지 않는다.

## 환자 A — 오른쪽 발목 염좌

### S

- 어제 계단을 내려가다 잘못 착지하면서 오른쪽 발목이 안쪽으로 꺾임.
- 오른쪽 외측 복숭아뼈 통증으로 걷기 어려움을 호소. 현재 통증 NRS 8/10.
- 이전 정형외과 X-ray에서 뼈에 문제가 없다는 설명을 들었다고 보고.
- 수년 전 같은 쪽 발목 염좌 및 인대가 늘어났다는 과거력 보고.
- 기존 전사상 수면·대소변 문제, 현재 질환·복용약, 흡연·음주를 부인. 직업은 주부.
- 저녁 걷기 운동을 계속해도 되는지 질문.

### O

- 의료진 발화상 맥은 빠르고 미끄러운 양상, 혀는 붉고 백태가 있음.
- 우측 외과 아래 부종 관찰. 부종 측정값 좌 43cm, 우 45cm. 측정 위치·방법은 확인 가능한 영상 범위에서 별도 검수.
- 발목 ROM: 좌 배굴 20°·저굴 35°, 우 배굴 10°·저굴 25°.
- 보행 평가, 오타와 관련 촉진, 인대 촉진, 불안정성 검사를 시행하는 과정이 전사됨. 개별 검사 양성·음성 및 인대별 압통 결과는 현재 자료로 확정하지 않음.
- 의료진이 영상 재검토 후 골절·탈구 소견이 없다고 설명한 내용이 전사됨. 실제 영상 판독을 이 문서에서 수행한 것은 아님.

### A

- 의료진이 오른쪽 발목 염좌 2단계로 평가한다고 설명함.
- 확정 변증명 발화는 확인되지 않음. 치료 설명에 등장하는 '어혈'을 자동으로 특정 변증명으로 확정하지 않음.

### P

- 주 3회 내원하여 침·약침·한약·뜸 치료를 병행할 계획을 설명함.
- 회복에 약 4~8주가 소요될 수 있고 만성 불안정성이 남을 수 있다고 설명함.
- 휴식, 초기 48시간 냉찜질 후 온찜질, 누울 때 발을 높이는 방법을 안내함.
- 걷기 질문에 체중 부하가 있는 무리한 운동과 당분간 걷기를 삼가고 누워서 가벼운 스트레칭을 하도록 답변함.
- 위 내용은 녹음에 있는 계획·안내를 기록한 것임. 이 문서에서 새 생활·운동 지침을 추가하지 않음.
- 오늘 침·약침·뜸 시행 완료, 선택 혈자리, 약침 종류·용량, 구체적인 한약 처방명은 확인되지 않음.

### 다음 재진 질문

전체 공통 12개 질문을 유지하면서 아래 항목을 먼저 표시한다.

- 오른쪽 발목 통증은 현재 NRS 몇 점인지? 초진 8점과 비교.
- 걷기와 계단 내려가기 불편은 어떻게 달라졌는지? 활동별 답변·자체 불편 점수를 따로 기록. 초진 기능 점수는 미측정이므로 임의로 만들지 않음.
- 부종은 어떻게 달라졌는지? 다시 측정하면 동일 위치·방법을 확인하고 좌우를 구분.
- 실제로 받은 치료와 이후 반응은 무엇인지? 예정된 치료를 받은 것으로 가정하지 않음.
- 한약을 실제 처방·복용했다면 복약 여부와 불편감 확인. 처방명·기간은 별도 확인.
- 냉·온찜질, 발 높이기, 활동 조절을 어떻게 실천했는지?

### 평가 시 틀린 출력

- 좌우 수치 반전 또는 PDF의 좌 저굴 40°·우 저굴 20°를 영상값 대신 사용.
- NRS 8을 기능 불편 점수 8로 자동 복사.
- 검사 시행을 근거로 오타와 음성·전거비인대 압통 양성 등을 확정.
- 침·약침·뜸을 '오늘 시행함'으로 기록하거나 혈자리·처방명을 추가.
- 걷기 질문을 미답변 질문으로 처리. 초진 대화에서는 답변이 있었으므로 재진에서는 실천·이해 여부를 확인.

## 환자 B — 소아 야뇨

### S

- 보호자 보고: 약 2개월 전부터 밤에 소변을 지림. 밤마다 약 2회, 주로 자정 이후이며 양은 적은 편.
- 6개월 이상 야간 소변을 가린 시기는 없었다고 보고. 낮 요실금은 부인.
- 야뇨 후 잠에서 깨서 알게 된다고 답함. '잠에서 깨서 화장실에 2회 감'으로 바꾸지 않음.
- 하루 배뇨 약 10회, 양은 많지 않음. 배뇨 후 다시 화장실에 가고 싶어 하거나 참는 모습에 대한 복합 질문에 긍정 답변. 두 증상을 각각 확정하려면 추가 확인 필요.
- 배뇨통·배뇨 시작 어려움·약한 소변줄기는 부인.
- 식욕 저하, 설사, 추위를 탐. 발달·유치원 수업은 또래 수준이라고 보고.
- 수면은 잘 자고 코골이는 없다고 답변. '입을 벌리고 자는지'는 질문에 포함됐지만 개별 답변은 확정되지 않음.
- 부친의 어린 시절 야뇨 가족력 보고. 현재 복용약·기진단 질환·수술력은 부인.

### O

- 의료진 발화상 맥이 약함, 혀가 약간 부어 있고 설태가 있음.
- 참고 대본에는 '얇은 설태'가 있으나 기존 전사에는 그 두께가 명확하지 않으므로 최종 음성 검수 전에는 두께를 확정하지 않음.
- 소변검사·영상검사·복진 결과 등 확인되지 않은 검사를 추가하지 않음.

### A

- 의료진이 발화한 평가명: 과민성 방광염. 연화가 실제 영상 표현으로 확인함.
- 의료진이 설명한 한의학적 변증: 비폐기허.
- 어린이집 입학 후 심리적 변화와 방광의 예민함이 관련될 수 있다고 설명함. 환자·보호자가 독립적으로 확인한 원인으로 단정하지 않음.
- 발화된 평가의 기록이며 감염성 방광염 확진 또는 특정 진단의 임상적 타당성 검증을 의미하지 않음.

### P

- 이침 치료 계획을 설명함. 실제 시행 여부·이침 부위는 확인되지 않음.
- 보중익기탕 처방 계획과 하루 3회 식후 30분 복용 지도를 설명함.
- 2주 뒤 재내원 안내. 처방 일수·복용 시작일·회당 용량은 명시된 것으로 간주하지 않음.
- 아이가 편안한 환경을 유지하도록 돕고 스트레스·수면 부족 시 증상이 나타날 수 있다고 안내함.
- 성장·적응 과정에서 호전될 수 있다는 예후 설명을 기록하되 확정적 치료 효과를 추가하지 않음.

### 다음 재진 질문 및 그래프

전체 공통 12개 질문을 유지하면서 보호자에게 아래 내용을 먼저 확인한다.

- 밤에 소변을 지리는 횟수의 변화: 초진 보고는 밤마다 약 2회. 같은 관찰 기간·단위로 비교.
- 지난 7일 중 야뇨가 있었던 밤 수: 새로 질문하고 '일/주'로 별도 그래프. 초진 수치는 직접 답한 값이 없으므로 7일로 자동 입력하지 않음.
- 낮 배뇨 횟수 및 배뇨 후 불편 변화: 초진 약 10회/일. 야뇨 횟수와 별도 그래프.
- 한약 실제 복용 횟수, 누락·중단, 복용 후 불편.
- 식욕·설사·수면·추위 및 생활환경 변화.
- 각 항목에 호전 / 동일 / 악화 / 불명확과 상세 답변. 야뇨 빈도에 통증 NRS를 적용하지 않음.

### 평가 시 틀린 출력

- 보호자 보고를 아동 본인의 발화로 처리.
- 밤에 소변을 지림을 야간 화장실 방문으로 바꿈.
- 질문에만 있는 입 벌리고 자기·복진 결과를 관찰 사실로 기록.
- 이침을 시행 완료로 기록하거나 2주 뒤 내원을 14일분 처방으로 변환.
- 대본·용어 사전을 근거로 발화하지 않은 검사 결과·진단을 추가.
