# 필기 중 도구 버튼 깜빡임 수정 (2026-10-09)

## 원인과 변경

펜/지우개 접촉마다 `strokeActive`가 바뀌면서 오른쪽 위 도구·앞뒷면 버튼의 `disabled`가 켜졌다 꺼졌다. 전역 `button:disabled`는 불투명도 0.5, 도구 버튼 스타일은 0.45를 적용해 글자의 각 획마다 버튼 밝기가 변했다. 선택한 도구가 바뀌는 현상은 아니었다.

필기 접촉으로 잠긴 탐색 영역만 `data-stroke-active`로 구분하고, 해당 영역의 버튼 불투명도를 1로 유지한다. 실제 비활성화와 도구 변경 방지 동작은 유지하며, 처리 중 또는 이전 도해 읽기 전용 상태에는 이 표시 예외를 적용하지 않는다.

## 검증

- 수정 전 로컬 브라우저에서 펜 접촉 전/후 불투명도 1, 접촉 중 도구 버튼 0.45·앞뒷면 0.5를 재현했다.
- 수정 후 펜 접촉 시작·이동·종료 모두 다섯 버튼의 불투명도 1을 확인했다.
- 접촉 중 다섯 버튼은 계속 비활성화됐으며, 도구 전환을 시도해도 펜 모드를 유지했다. 접촉 종료 후 전환 가능한 상태로 복구됐다.
- 지우개 접촉 시작·이동·종료에서도 불투명도 1을 유지했다. 필기 생성과 지우기 동작을 확인했다.
- TypeScript 검사와 임시 복사본 빌드 통과. 실물 Apple Pencil 대신 `pointerType=pen`, `isPrimary=false` 입력으로 확인했다.
- 위 검증의 테스트 페이지와 프레임 설정은 별도 로컬 복사본에만 적용했으며 운영 소스에는 포함하지 않았다.
