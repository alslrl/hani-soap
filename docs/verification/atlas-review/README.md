# Atlas 전신 혈자리 검수

2026-10-09. 연화 요청으로 만든 별도 검수 화면이며 진료 앱의 인체 도해를 교체하지 않았다. 2026-10-09 사용자가 검수 화면과 문서의 공유를 승인하여 커밋·푸시한다. 이는 개별 혈자리 임상 위치 361종의 승인과 별개다.

## 사용

`index.html`은 그림과 데이터를 포함한 독립 파일이다. 브라우저에서 열거나 이 디렉터리만 로컬 서버로 제공한다. 현재 미리보기 주소는 `http://127.0.0.1:8766/`이다. PC에서만 접근하는 로컬 주소이며 세호에게 공유할 배포 주소가 아니다.

1. 부위 또는 혈명·코드를 선택한다.
2. 선택점 확대에서 위치 설명과 점을 대조한다.
3. 위치 맞음 / 위치 수정 / 판단 보류를 기록하고 메모를 남긴다. 점을 끌어 수정할 수 있다.
4. 검수 결과 내려받기로 JSON을 보관한다. 다른 컴퓨터에서 이전 결과 불러오기로 이어서 검수할 수 있다.

브라우저 저장은 같은 주소와 브라우저에서만 유지된다. 세호와 공유할 결과는 내려받은 JSON을 사용한다. 검수 상태 버튼은 시술 시행 확인이 아니다.

## 범위와 보정

- 정규 경혈 361종, 부위 분류 25개. 부위 분류도 출처 텍스트 기반 초안이다.
- Atlas 앞면·뒷면·옆면·머리의 원본 도해를 사용했다. 몸 윤곽 밖/경계의 점은 가장 가까운 윤곽 내부의 화면 표시 후보로 이동했다. 이 방법은 해부학적 취혈 위치를 결정하는 방법이 아니다.
- 발목 16개는 별도 준비한 데모 표시 후보를 사용했다. 사용자의 발목 그림 확인은 기록했지만 361개 개별 임상 위치를 승인한 것으로 간주하지 않는다.
- 원본 좌표는 `display-candidates.json`의 `original_coordinate`에 보존했다. 표시 후보와 원본 좌표를 구분하며 모두 임상 검수 전이다.
- 환자 기준 좌우의 전체 인스턴스가 아니다. 원본에서 보이지 않는 내측·후두·손바닥·발바닥·회음 등은 판단 보류와 메모를 남기고 별도 도해 검수가 필요하다.
- 좌표가 없는 경외기혈 48종과 이침 자료는 이 화면에 넣지 않았다. 아시혈·압통점의 실제 시술 기록은 기존 앱 기능과 별도다.

## 산출물

- `index.html`: 전신 검수 화면
- `overview.png`: 전신 개요 그림
- `display-candidates.json`: 원본과 표시 후보 좌표
- `page-index.json`: PDF 쪽별 혈자리 코드 목록
- `../../../output/pdf/atlas_전신_혈자리_검수.pdf`: 72쪽 검수용 PDF (표지 포함)
- `../../../scripts/build_atlas_review.py`: 생성 스크립트. 기존 로컬 `data/acupoints` 자료와 Atlas 발목 표시 후보를 입력으로 사용한다.
