## 동작

- 기본 **부위 선택**: Pencil·마우스로 부위를 누르거나 손가락으로 짧게 탭하면 기존 혈자리 팝업을 연다. 필기 획을 만들지 않는다. 선택 후에도 모드를 유지한다.
- **펜**: 체크·동그라미·글씨 모두 메모로 기록한다. 모양 인식과 자동 팝업은 실행하지 않는다. 손바닥·손가락 접촉은 필기나 선택으로 처리하지 않는다.
- **지우개**: 닿은 필기 획 전체를 지운다. 점 참고 레이어·인체 이미지·선택한 혈자리·시술 기록은 지우지 않는다. 표시 반경은 화면에서 약 14px이며 확대해도 같은 체감 크기를 유지한다.
- **되돌리기**: 한 번 문질러 지운 여러 획을 한 번에 복구한다. 그리기·지우기 이력은 시술 종류·앞뒷면·도해 버전별로 나누며 최대 50개를 현재 화면에서 보관한다. 저장 형식에는 이 편집 이력을 추가하지 않는다.
- 이전 도해는 읽기 전용이며 세 도구를 비활성화한다. 기존 체크 종류와 저장된 원본 좌표는 보존한다.
- 활성 도구는 검은색으로 표시하고 최소 44px 버튼과 방향키·Home/End 전환을 지원한다. 세로·가로 화면 모두 오른쪽 위에 위치한다.

기존 normalized 1000×1000 저장, annotation revision·원본 보존, 시술 확정 경계와 화면 스크롤 고정은 유지한다.

## 검증

- TypeScript와 입력·지우개·되돌리기·좌표 관련 검사 30개 통과. 긴 선의 중간과 빠른 드래그의 교차, 한 번의 삭제에 대한 복구, 원본 불변성·레이어 분리를 검사했다.
- 별도 로컬 스냅샷의 production build 통과. 최초 스냅샷은 동시 작업에서 추가한 공통 Disclosure 의존성이 빠져 실패했고, 원격에 반영된 최신 기준으로 다시 구성한 빌드는 성공했다.
- 브라우저: 기본 모드에서 손 클릭→혈자리 팝업→합곡 우측 선택 시 필기 0획. 펜 모드에서 체크 모양 두 획→메모 2획·자동 체크 0·팝업 0.
- 한 번의 지우개 드래그→필기 0획, 되돌리기 한 번→원본 2획 복구. 참고점 368개와 선택한 위치는 유지됐다.
- 저장·새로고침 후 기본 모드와 메모 2획 확인. 약침 전환 시 필기 0획, 침으로 돌아오면 2획 유지. 방향키로 펜 모드 전환 성공.
- 세로 834×1194와 가로 1366×1024에서 세 도구가 표시되고 동작하며 브라우저 오류 없음. 실제 Apple Pencil 기기는 직접 연결해 검사하지 않았다.
