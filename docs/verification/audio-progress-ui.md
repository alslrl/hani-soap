# 녹음별 음성 처리 진행 UI

2026-10-09. 기준 커밋 `62f9102`. 진행 중인 작업·이전 실패·최근 성공 전사가 한 화면에서 섞이는 문제를 녹음별 연결로 정리했다.

시각 방향은 기존 진료실의 흑백 표면·작은 아이콘·짧은 안내를 유지한다. 내용은 현재 녹음 한 건의 단계와 시간, 그 녹음의 전사, 접힌 이전 처리 내역 순서다. 단계 변화와 진행 아이콘은 작업 상태를 따라가며 감소된 모션 설정에서는 회전을 멈춘다. 전사 편집 중에는 새 녹음·파일 선택·이전 음성 선택을 막아 입력을 보존한다.

- 녹음 → 파일 저장 → 전사 → 화자·용어 정리 → SOAP 작성 → 검토 대기. 완료·진행·대기·중단 상태와 구체적인 안내를 표시한다. AI 단계의 임의 퍼센트나 예상 완료 시간은 만들지 않는다.
- `recording_id`와 전사 ID를 이용해 최종 전사·검토 후 SOAP 재생성·재진 후보 분석을 같은 음성에 연결한다. 케어·브리핑 작업은 음성 진행으로 표시하지 않는다.
- 녹음 중 실시간 대화 표시와 종료 후 최종 전사를 구분한다. 이전 실패는 접힌 내역에 남고, 사용자가 선택했을 때 그 녹음의 진행·결과를 표시한다.
- 새 실패 작업에 이전 성공 전사를 자동으로 붙이지 않는다. 전사 결과와 SOAP에는 기록 출처의 시각과 녹음 길이를 표시한다. 음성과 연결되지 않은 SOAP는 저장된 전사 버전을 표시한다.
- 완료·실패 시 처리 시간을 멈춘다. 실패 단계가 저장되지 않은 과거 작업은 특정 실패 단계를 임의로 추정하지 않는다.

## 무음과 오류 전달

Workflow 단계 사이에서 오류가 직렬화되어도 알려진 코드·실패 단계는 보존한다. 최종 작업의 `result.failure`에 코드·단계·재시도 여부·안전한 문구를 저장한다. 기존 JSONB 결과 필드를 사용하므로 DB 마이그레이션은 없다. provider 요청·응답 본문이나 임의 오류 내용은 사용자 문구로 전달하지 않는다.

`TRANSCRIPTION_EMPTY`는 “음성이 감지되지 않았어요”와 다시 녹음 동작을 표시한다. 사용 가능한 최종 전사와 SOAP가 만들어지지 않았음을 안내한다. 일시 오류는 저장된 동일 음성의 전사 재시도를 제공하고, 음성 파일이 없거나 업로드되지 않았다면 파일을 다시 선택한다. 원문·승인 기록과 두 ASR 채널의 원본/부분 성공 저장 방식은 유지한다. 음성과 무관한 필기 작업의 기존 오류 처리는 유지한다.

과거에 일반 오류로 저장된 실패를 운영 DB에서 소급 변경하지 않는다. 이번 변경은 앞으로 발생하는 실패에 원인 코드를 남긴다.

## 검증

- TypeScript와 production build 통과.
- 최신 메인 통합 후 단위 테스트 191개, 서버 테스트 52개 통과.
- 격리 로컬 브라우저 4개 통과: 단계 전환·경과 시간 멈춤·이전 실패 분리·전사/SOAP 출처·무음 재녹음 안내·좁은 화면·미저장 전사 보존·기존 화자/용어/본문 검토.
- 실물 마이크·iPad 검사나 실제 모델 호출을 추가하지 않았다. 서버 검사는 가상 데이터, UI 검사는 합성 작업 상태를 사용한다. 처음 로컬 검수 시 운영 DB와 배포를 변경하지 않았다. 이후 사용자 요청에 따라 배포와 영상 음성의 실제 처리를 진행한다.

메인의 후속 `alignment_review` 단계도 전사 누락 확인 안내로 표시한다. 통합 시 ASR 개선의 `transcribeSourcesStep → refine → transcribeStep` 분리와 원음 정규화를 보존하고, 해당 Workflow의 실패 인코딩을 유지한다.
