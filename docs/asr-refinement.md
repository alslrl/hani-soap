# 실제 동영상 전사 보완 (dual-asr-v2.1)

2026-10-09. 발목 원본 8분 54초의 v1 결과에서 문자 경계가 단어를 잘랐고, 62개 표시 구간 중 28개가 화자 미확인으로 남아 검사 수치가 SOAP에서 누락됐다. 화면의 36개 경고는 본문이 없는 8개 source group까지 센 값이었다. 소아 원본 3분 18초의 운영 기준 실행은 recording fec29cf0-3786-44e0-9f52-7a6a900c79d9로 구분한다. 뒤에 생성된 791바이트의 별도 webm 실패는 원본 MP3 비교 대상이 아니다. 이 결과와 원본을 그대로 보존한다.

## 처리 순서

1. 원음은 저장소에 보존한다. 서버에서 보내는 사본은 FFmpeg로 16kHz mono FLAC, loudness -20 LUFS 목표로 변환하고 원래 메타데이터를 제거한다. 발화 식별정보를 음성에서 삭제하는 기능은 아니다.
2. `gpt-transcribe` 본문과 `gpt-4o-transcribe-diarize` 화자·시간을 각각 저장한다. 본문 모델에는 일반적인 한국어 진료 맥락만 제공하며 사례 정답이나 예상 수치를 넣지 않는다.
3. 시간 겹침은 해당 문장의 시간 표시만 보류한다. 화자는 독립적인 문장 근거로 대응하며 전체 대화를 폐기하지 않는다. 문자 비교는 대응 위치의 단서로만 사용한다. 실제 본문 분할은 문장 경계에서 하며, 한 경계의 차이를 긴 화자 발화 전체로 전파하지 않는다. 본문에 있는 문자와 문장 순서를 보존한다.
4. 미확인 문장은 GPT-6.1 Sol로 기존 source ID와 정확한 인용의 대응을 검토한다. 후보 밖의 ID, 인용 불일치, 낮은 문자 일치도, 숫자 충돌, 반복되는 짧은 filler는 자동 수락하지 않는다.
5. 화자 전사에만 있는 발화는 최대 16개를 시간대별로 다시 전사한다. 동시에 최대 4개 호출하며 각 결과를 작업에 저장해 재시도 때 재사용한다. 기존 발화와 높은 일치도를 보이고 시간 순서가 검증되는 응답만 별도 표시로 삽입한다. 실패·충돌·한도 밖 항목은 누락 확인 대상으로 보존한다. 일치도는 임상적 확정이나 calibrated confidence가 아니다.
6. 역할 추정 후 SOAP를 생성한다. 원문 인용에 연결된 수치·관찰 체크 목록을 만들고, 관련 섹션과 근거에서 빠진 supported 항목이 있으면 한 번 더 생성한다. 남은 누락은 화면의 `SOAP 반영을 확인할 원문`에서 확인한다. unknown 역할, 질문, 검사 안내를 확정 관찰로 바꾸지 않는다.

재전사 응답이 추가되면 결합본은 원래 본문보다 길어질 수 있다. 두 최초 원본은 불변 revision으로 보존되며, 추가 구간은 `alignment_method=audio_recheck`와 원래 source ID·시간대·재전사 결과를 갖는다. 의료진의 수동 검토·기존 승인 기록은 덮어쓰지 않는다.

긴 최초 전사와 문장 검토를 별도 Workflow step으로 실행한다. 같은 모델의 성공 채널은 부분 재시도 때 재사용한다. FFmpeg 실행은 Node step에서만 수행한다. `ffmpeg-static@5.3.0`의 GPL-3.0-or-later 라이선스와 포함 바이너리의 고지 사항을 따른다.

## 식별정보 가림 v2

등록 이름과 정형 식별정보에 더해 명시적인 자기소개·의료진 소개와 생년월일 응답에서 이름·날짜를 로컬 규칙으로 발견한다. 발견된 값은 같은 요청의 문장과 인용 전체에 일관되게 가린다. 선택 설정 `HANI_PRIVACY_CLINICIAN_NAMES`로 의료진 이름을 추가할 수 있다. 문맥 없는 이름·날짜, 잘못 전사된 이름, 모든 식별정보를 탐지한다고 보장하지 않는다. 다른 이름을 차트 환자의 실제 이름으로 자동 등록하지 않는다.

가림은 후속 텍스트 요청에만 적용한다. 원음·실시간 음성·손글씨 이미지는 내용 가림 대상이 아니다. 음량 보정과 메타데이터 제거를 음성 익명화로 설명하지 않는다. 원문과 검토 화면은 접근 권한 아래 보존한다.

## 검증

단위 검사 175개와 서버 검사 47개, 별도 FFmpeg 실제 PCM 변환·범위 검사 통과. 실제 저장된 발목 전사의 재결합과 OpenAI 재검토·재전사·SOAP 호출에서 좌우 둘레와 가동범위 수치가 복원됐다. 원본/수정본의 문장 수가 다르므로 화자 미확인 개수만으로 정확도를 비교하지 않는다. 문장 잘림, 미확인 본문 비율, 수치·좌우·계획 보존, 원문 근거, 처리 시간과 호출량을 함께 비교한다.

운영 환경의 최종 비교는 `output/audio/asr-refinement/`에 모델 결과·작업 ID·검증 내용을 남긴다. 기대 출력은 평가에만 사용하고 전사·SOAP 입력으로 넣지 않는다.

발목의 원음 부분 재전사 16개 중 1개만 시간·문구 검사를 통과해 추가됐다. 화자 전사에만 남은 25개는 여전히 대조 대상이다. 검수 기준의 ‘뜸’과 ‘과민성 방광염’은 최신 본문에서 ‘등’과 ‘과민성 방광’으로 남아 원음 검토가 필요하다. 불확실한 용어를 정답 문서로 강제 치환하지 않았다. 추가 검토의 비용·지연이 커졌으므로 속도 개선은 후속 과제로 남는다.

소아의 생년월일 ‘일생’ 표기 누락을 보완한 최종 배포에서 기존 전사로 SOAP를 재생성했다. 후속 요청에 이름 2곳·생년월일 1곳 가림, 검사 목록 미반영 0개를 확인했다. 두 사례 모두 새 초안으로 보존했고 임상 승인을 누르지 않았다. 검증 시작 시 승인 기록 4건과 기존 전사 11건의 해시가 유지됐다. 소아의 별도 좌측 발목 침 기록은 기존 확인 입력이며 영상에서 생성한 것으로 해석하지 않는다.

최종 단위 검사 181개, 서버 검사 47개, TypeScript, 프로덕션 빌드, 데모 스키마 검증을 통과했다. 상세 근거와 작업 ID는 `output/audio/asr-refinement/comparison.json` 및 사례별 원본 결과 파일에 있다. 음량 보정·본문 요청 맥락도 함께 바뀌었으므로 개선을 단일 요인의 효과로 단정하지 않는다.
