# 본문 전사와 화자·시간 구간의 결합

2026-10-09. 전체 녹음과 업로드 파일을 두 전사 경로로 병렬 처리한다.

| 역할 | 기본 모델 | 요청 |
| --- | --- | --- |
| 본문 | gpt-transcribe | 파일과 `languages[]=ko`. 대본·정답·등록 이름 힌트 없음 |
| 화자와 시간 | gpt-4o-transcribe-diarize | `diarized_json`, `chunking_strategy=auto` |
| 의료진·환자·보호자 역할 | 기존 교정 모델 설정, 기본 gpt-6.1-sol | 결합 본문의 화자 그룹별 역할 후보와 원문 근거 |

`OPENAI_MODEL_TEXT_TRANSCRIPTION`과 `OPENAI_MODEL_DIARIZATION`으로 분리 설정한다. 기존 `OPENAI_MODEL_TRANSCRIPTION`은 화자 구간용 모델의 하위 우선순위 호환 설정으로 유지한다. 모델을 암묵적으로 바꾸는 fallback은 없다. 실시간 스트리밍 경로는 이번 변경 범위 밖이다.

## 원문과 재시도

각 모델의 원본 결과와 결합본을 별도의 불변 전사 revision으로 저장한다. 작업의 `diarizedTranscriptId`, `contentTranscriptId`, `transcriptId`가 각각 해당 문서를 가리킨다. 결합본의 `text`는 본문 모델 결과와 정확히 같아야 하며, 전체 구간을 이어 붙인 문자열도 같아야 한다.

한 경로가 실패해도 다른 경로의 성공 결과를 보관한다. 같은 입력·모델·파이프라인 버전으로 재시도하면 보관한 경로를 재사용하고 빠진 경로만 다시 호출한다. 두 결과가 준비되기 전에는 SOAP를 진행하지 않는다. 모델·입력이 다른 과거 실패 작업의 중간 결과는 재사용하지 않는다.

## 화자 대응과 한계

같은 화자의 연속 구간을 묶은 다음, 공백·문장부호를 제외한 문자 순서를 로컬 편집거리 정렬로 대조한다. 대응 위치로 본문 원문을 잘라 화자·시간 범위를 연결한다. 본문 문장을 LLM으로 다시 써서 화자에 억지로 맞추지 않는다.

전사 차이는 `transcription_changed`, 자동 대응 상태는 `alignment_status`에 표시한다. `source_segment_ids`는 묶인 원래 화자 구간 ID들을 보존한다. 검토 revision 사이의 안정적인 ID는 기존 `source_segment_id` 계약을 따른다.

화자 경계의 삽입·불안정한 대응, 낮은 문자 일치도 등은 해당 구간의 화자와 시간을 미확인으로 남긴다. 시간 구간이 겹치거나 두 전사가 크게 다르거나 정렬 행렬이 1,600만 셀을 넘으면 본문 전체를 미확인 구간으로 보존한다. 이 임계값과 ‘대응됨’은 음성 인식 정확도나 의학적 정확성을 뜻하지 않는다. 단어 단위의 강제 음성 정렬도 아니다. 긴 녹음·중첩 발화의 별도 품질 검증이 필요하다.

전사 검토 화면에서 표현 차이, 화자 대응 확인 항목, 두 모델의 원본을 열어 볼 수 있다. 사용자가 화자 역할을 수정하면 새 검토 revision과 이후 SOAP에 반영되며, 기존 전사와 승인 기록은 보존한다. 전체 내용을 자유 편집한 경우에는 기존과 같이 부정확한 시간·화자 연결을 유지하지 않는다.

## 후속 AI와 개인정보

용어 검토·화자 역할 추정·SOAP의 기본 입력은 결합된 새 본문이다. [식별정보 1차 가림](text-privacy.md)은 후속 텍스트 요청에 계속 적용한다. 두 전사 요청 모두 원음을 OpenAI로 전달한다. 원음 마스킹, 로컬 전사, ZDR 계정 설정, 원음 보관·삭제 정책을 구현한 것으로 설명하지 않는다.

## 검증

- 앞서 저장한 실제 합성 음성의 두 모델 응답으로 8개 발화를 대응하고 본문·시간·원래 ID 보존을 검사했다.
- 화자 경계에 새 문장이 생긴 경우, 서로 다른 내용, 겹치는 시간, 반복·삭제 구간, 처리 범위 초과 시 미확인으로 보존하는 검사를 수행했다.
- 실제 격리 저장소에서 두 원본·결합본의 별도 revision, 사용자 역할 수정, 이후 SOAP 입력과 기존 승인 기록 보존을 확인했다.
- 실제 64초 합성 음성으로 두 전사 API → 화자 역할 → 용어 검토 → SOAP를 다시 실행했다. 새 본문의 ‘김서연’, ‘발을 높여’가 유지됐고, 8개 발화의 역할·현재 통증 5점·발 높이기 안내가 반영됐다. 화자 미대응은 0개, 전체 처리 약 47.6초였다. 합성 사례 한 건의 결과이며 일반 정확도·지연 보장이 아니다.

공식 API 기준: [파일 전사와 화자 구분](https://developers.openai.com/api/docs/guides/speech-to-text).
