# 2026-10-21 공개 정리 검증 기록

## 실제 실행한 검사

- 공개 파일 검사와 검사기 자체 테스트에서 제외 경로·알려진 비밀값 패턴 위반 0건을 확인했습니다.
- 타입 검사와 단위 테스트 209개, 서버 테스트 52개를 통과했습니다.
- 가상 데모 데이터의 스키마·ID 관계·상태·시간·사진 무결성 검사 및 31개 메모리 내 오류·경계 검사를 통과했습니다.
- 361종 카탈로그와 남녀 도해 참고점 파생 결과의 재생성 일치 검사를 통과했습니다. 남녀 참고점 배열은 이번 자료 정리 전후가 같습니다.
- 연구 JSON에서 제외할 위치 설명 필드가 없고, 변증명 출처가 KTKP 624행·573종이며 파생 텍스트 목록이 같은지 회귀 검사합니다.
- Markdown 문서 45개의 상대 파일 링크가 모두 존재함을 확인했습니다.
- 외부 API 키·Supabase 연결 없이 격리된 작업 사본에서 프로덕션 빌드를 통과했습니다. 처음에는 작업 사본 밖 의존성으로 향하는 심볼릭 링크를 Turbopack이 거절했으며, 같은 의존성의 작업 사본 내 복사본으로 다시 확인했습니다. 이 때문에 앱 코드를 바꾸지는 않았습니다.
- 비공개 bundle 백업의 완전한 Git 이력을 검증했습니다. 별도 사본의 모든 대상 브랜치에서 제외 경로가 사라진 것을 확인했고, Gitleaks 8.30.1의 전체 참조 이력 검사에서 탐지 0건을 확인했습니다.
- pre-push 검사기가 옛 비공개 자료를 포함한 이력은 거절하고 정리된 이력은 허용함을 시험했습니다.

## 범위와 한계

위 검사는 임상 정확성·실제 환자 운영·모든 권리 관계·모든 비밀값 부재에 대한 보증이 아닙니다. DB 통합·브라우저 E2E·실물 iPad·실제 모델 호출·외부 발송은 이번 변경에서 다시 실행하지 않았습니다. 유료 AI 호출이나 실제 환자 자료를 사용한 검사는 하지 않았습니다.

공개 이력 재작성은 도달 가능한 원격 브랜치의 자료 정리이며, GitHub의 이전 커밋 URL·캐시나 외부 복제본을 자동 회수하는 작업이 아닙니다. [공개 파일과 이력 관리](publication-safety.md)의 후속 지원 절차와 한계를 확인하세요.
