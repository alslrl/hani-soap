## 데모 적용

- 기존 발목 염좌 사례는 우측이다. 이번 방문에서 실제로 선택·확인한 시술과 혈자리만 우측 기록에 연결한다. 다른 환자에서는 좌우를 새로 확인한다.
- 침·약침 등 각 시술의 선택은 독립 저장한다. PDF의 침 루틴을 약침·뜸·화침까지 실제 시행한 것으로 자동 복사하지 않는다.
- 후보를 모두 자동 체크하지 않는다. 시술자가 실제 시연할 혈자리를 선택한다.
- 기존 초진 녹음에 없는 혈자리를 그 녹음의 정답 SOAP에 넣지 않는다. 추가 시연에서 확인한 선택을 별도 시술 기록으로 반영한다.
- 자침 깊이·침 규격·유침시간 등은 후보 선택 시 자동 채우지 않는다. 이 데모 문서는 혈명·코드·영역만 추출했다.
