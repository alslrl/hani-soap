## HaniSOAP에 적용할 흐름

HaniSOAP은 수납·청구를 구현하지 않으므로 원본의 수납 완료를 모방해 자동 완료 처리하지 않는다. 다음 세 방문 상태를 사용한다.

1. 대기: 오늘 방문이 준비된 상태.
2. 진료 중: 진료 시작 또는 해당 방문의 첫 녹음·파일 처리를 시작한 상태.
3. 진료 완료: 의료진이 오늘 진료 마침을 선택한 상태.

환자 선택은 화면 이동이며 상태 변경을 대신하지 않는다. 녹음 정지는 오디오 입력만 종료한다. SOAP 승인과 방문 완료를 분리해 진료 후 전사·검토가 계속될 수 있게 한다. 기록은 빈 상태·초안·검토 필요·승인 완료를 별도 표시한다.

진료 중과 진료 완료 버튼은 PC의 환자·방문 헤더에서 관리한다. 아이패드에는 같은 방문의 상태를 표시한다. 녹음이 진행 중이면 기존 입력과 마지막 청크를 먼저 끝내고 방문을 완료하며, 이미 등록한 AI 작업의 결과는 원래 방문에 저장한다.
