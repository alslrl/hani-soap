# 재진 질문 및 경과 기록

정리일: 2026-10-09 (KST)
상태: 연화가 요청한 화면·기록 요구사항. 앱 구현 완료를 의미하지 않는다.

## 기본 화면

재진마다 아래 12개 항목을 모두 질문 목록에 표시한다. 항목마다 지난 답변과 날짜, 오늘 질문, 변화 선택 버튼, 상세 답변 입력란을 함께 보여준다. 관련성이 높은 항목과 미해결 질문을 먼저 배치하되 다른 항목도 접근할 수 있게 한다.

공통 입력 배치:

> 지난 기록: 10월 9일 — 계단 내려갈 때 불편
>
> 질문: 지난번과 비교해서 계단 이용은 어떤가요?
>
> [호전] [동일] [악화] [불명확]  상세 답변: ____________________

- 네 가지 변화 선택지는 지난 기록과 비교한 환자 보고 또는 의료진 확인 결과다. 기본 선택값을 두지 않는다.
- 모든 항목에 상세 답변란을 둔다. 자유 입력과 전사에서 가져온 환자 표현을 기록할 수 있고 의료진이 수정할 수 있다.
- 답변을 듣지 못한 경우 선택을 비워 두고 확인 상태를 '확인 안 됨'으로 저장한다. '불명확'은 실제 답변이 있지만 변화 판단이 어려운 경우다.
- 복약하지 않는 환자의 복약 항목 등에는 변화 선택과 별도로 '해당 없음'을 표시한다. 처음 확인해 비교할 지난 기록이 없으면 '첫 기록·비교 기준 없음'으로 표시하고 변화 선택을 강제하지 않는다.
- 변화 선택과 확인 상태는 별도다. 확인 상태는 '확인 완료 / 언급됐지만 추가 확인 필요 / 확인 안 됨'으로 관리한다.
- 한 항목에 여러 문제가 있으면 세부 질문별로 구분한다. 예를 들어 식욕 호전과 소화 악화를 하나의 호전 버튼으로 합치지 않는다.

복약·생활관리 항목의 변화는 실천 상태의 변화이며 질환의 호전과 구분한다. 질문·걱정 항목도 답변·이해 상태와 함께 기록한다. 네 가지 선택지만으로 복용 여부나 질문 해결 여부를 대신하지 않는다.

## 방문별 점수와 경과 시각화

목표는 환자가 올 때마다 주소증·통증·기능 경과를 함께 확인하는 것이다. 같은 내용을 같은 방식으로 평가한 점수끼리 비교한다.

### 통증

- 이번 앱의 통증 강도는 0~10 숫자를 선택하거나 말하는 NRS로 기록한다. 화면·차팅·그래프에 '통증 NRS (0~10)'로 통일하고 측정 도구와 단위도 저장한다.
- 기존 계획의 'VAS 8·7·6·5' 데모도 'NRS 8·7·6·5'로 정리한다.
- 통증 없음과 상상할 수 있는 가장 심한 통증의 양 끝 설명을 표시한다.
- 기본 질문은 현재 통증으로 두고, 평균·최악 통증이나 활동 시 통증을 추가하면 각각 별도 시리즈로 기록한다.
- 여러 통증 부위는 부위·좌우별로 구분한다. 활동 시 통증과 안정 시 통증도 섞지 않는다.

### 주소증과 기능

- 주소증이 통증이면 해당 통증 점수를 연결하고 같은 답변으로 점수를 중복 생성하지 않는다.
- 비통증 주소증은 구체적인 증상에 맞는 강도 점수 또는 횟수·지속시간을 선택한다. 증상 불편 정도 0~10을 쓰는 경우 '증상 불편 점수'로 표시하고 통증 VAS나 검증된 질환 척도로 부르지 않는다.
- 기능은 지난번 정한 같은 활동을 반복 확인한다. 예: 계단 내려가기, 걷기, 팔 올리기.
- 기능 불편 정도를 0~10으로 기록할 경우 0은 불편 없음, 10은 해당 활동의 불편이 가장 심함으로 고정한다. 이는 앱의 자체 기능 불편 점수이며 통증 VAS나 검증된 기능 척도로 부르지 않는다. 활동 수행 가능 여부와 구체적인 제한은 상세 답변에 함께 남긴다.
- 질환별 검증된 기능 척도를 사용할 경우 척도 이름·범위·점수 방향을 따로 보존한다. 다른 척도나 활동의 값을 같은 그래프로 합치지 않는다.

### 표시 방식

- 환자와 함께 보는 경과 화면의 기본 표현은 항목별 독립 선 그래프다. 여러 항목을 합친 점수 표나 하나의 그래프로 보여주지 않는다.
- 화면 순서는 '통증 변화 → 통증 NRS 그래프', '계단 내려가기 불편 → 해당 활동의 불편 점수 그래프', '걷기 불편 → 별도 그래프', '팔 올리기 불편 → 별도 그래프'처럼 항목 제목 바로 아래에 해당 그래프를 둔다. 실제 기록한 항목만 그래프로 표시한다.
- 통증이 여러 부위이면 부위·좌우별로, 기능은 활동별로 독립 그래프를 만든다. 주소증이 통증과 동일하면 같은 통증 그래프를 한 번만 표시한다.
- 각 그래프의 가로축은 방문 날짜, 세로축은 해당 점수다. NRS와 자체 기능 불편 점수는 각각 0~10 범위로 고정하고 항목명·척도명·단위·양 끝 설명을 표시한다. 다른 범위의 척도는 해당 범위를 사용한다.
- 환자와 함께 보기에서 제목·숫자·날짜를 크게 표시한다. PC의 넓은 화면은 그래프를 나란히 놓고 좁은 화면은 위아래로 배치하되 각 그래프의 제목과 축은 독립적으로 유지한다.
- 방문점에 점수를 표시하고 선택하면 해당 날짜의 호전 / 동일 / 악화 / 불명확과 상세 답변을 그래프 아래에 보여준다. 선택 전에는 최근 확인 답변을 표시한다.
- 변화 선택과 상세 답변은 항목별로 보존한다. 통증 호전과 계단 기능 악화를 하나의 방문 변화로 합치지 않는다.
- 점수가 없는 항목은 환자 답변과 변화 기록만 보여주며 그래프를 만들기 위해 점수를 추정하지 않는다.
- 예시 데이터가 필요하면 통증 NRS는 초진 8 → 재진 1의 6 → 재진 2의 5, 계단 내려가기 불편 점수는 7 → 6 → 4를 서로 다른 그래프에 표시한다. 이는 가상 예시이며 실제 환자 기록과 구분한다.

- 미확인 점수는 빈 값으로 저장하고 0점으로 표시하지 않는다. 누락 지점을 추정해 채우거나 연결해서 측정값처럼 보여주지 않는다.
- '호전' 등의 답변에서 숫자를 추정하지 않는다. 점수만으로 변화 버튼을 자동 확정하지 않는다. 점수와 상세 답변이 다르면 둘 다 보존하고 의료진이 확인한다.
- 초진 대비와 직전 확인 기록 대비를 구분한다. 직전 방문에서 확인하지 않았으면 마지막으로 확인한 날짜를 표시한다.

## 다음 방문에 자동으로 이어지는 내용

1. 다음 방문에서도 전체 12개 질문을 표시하고 마지막으로 확인한 답변·점수·날짜를 불러온다.
2. 지난 답변은 참고란으로만 표시하고 오늘 답변·선택·점수는 빈 상태에서 시작한다. 지난 점수를 오늘 값으로 자동 복사하지 않는다.
3. 미해결 질문과 추가 확인 필요 항목은 먼저 표시한다. 관련 복약·생활관리 안내도 질문에 연결한다.
4. 오늘 확인한 변화·상세 답변·점수는 오늘 방문에 새 기록으로 저장한다. 이전 방문을 덮어쓰지 않는다.
5. 오늘 언급되지 않은 항목은 확인 안 됨으로 남기고 이전 문제를 자동 해결 처리하지 않는다. 해결 여부는 의료진이 확인한다.
6. 상세 답변의 전사 근거나 수기 입력 출처를 남긴다. 복용·치료 후 불편 보고와 의료진의 인과관계 판단은 분리한다.

## 기록에 필요한 최소 필드

- 환자·방문·확인 날짜
- 항목 ID, 세부 증상·활동 ID, 부위·좌우
- 비교 기준 방문·날짜
- 변화: 호전 / 동일 / 악화 / 불명확 / 미선택
- 확인 상태와 해당 여부
- 환자 표현·상세 답변, 전사 근거 또는 수기 입력 출처
- 점수, 척도 이름, 단위, 범위, 양 끝 설명, 현재/평균/최악 등 측정 조건
- 다음 확인 질문, 해결 여부, 의료진 검토 상태
