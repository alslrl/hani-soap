# 혈자리가 모인 곳을 터치했을 때의 선택 제안

2026-10-09 이연화 제안. 세호에게 전달하기 위해 기록한다. 현재 앱에 구현 완료된 기능을 설명하는 문서가 아니다.

## 원하는 동작

손·발·얼굴 등 점이 가까이 모인 곳을 터치하면 인근 혈자리 후보를 띄워 사용자가 정확한 혈자리를 선택하도록 한다. 가장 가까운 한 점을 바로 확정하지 않는다.

예: 발등을 터치 → `해계 ST41 / 충양 ST42 / 함곡 ST43 / 태충 LR3` 중 터치 위치 인근의 후보 표시 → 한 항목 선택 → 그림에서 선택한 점을 강조 → 위치·환자 기준 좌우 확인 → 해당 시술에 추가.

위 예시는 선택 흐름 예시이며 네 혈자리를 모든 발등 터치에 고정으로 띄우거나 같은 위치로 취급하지 않는다.

## 선택 화면에 필요한 내용

- 후보마다 한글 혈명과 코드 표시. 후보가 많으면 혈명·코드 검색과 확대 제공.
- 후보를 누르면 그 점을 강조하고 위치 설명을 보여줘 서로 구별할 수 있게 한다.
- 현재 앞·뒤·옆면과 선택 부위를 반영한다. 화면상의 좌우와 환자 기준 좌우를 구분한다.
- 경혈 대신 아시혈·압통점을 기록할 수 있는 선택도 함께 제공한다.
- 취소할 수 있게 하고, 선택 뒤 기존 다른 혈자리나 다른 시술의 기록을 지우지 않는다.

## 확인할 기준

1. 손가락·펜으로 밀집 부위를 터치하면 후보 목록이 열리고, 원하는 항목을 선택할 수 있다.
2. 확대·이동 후에도 후보와 강조점이 그림상의 같은 위치에 대응한다.
3. 같은 화면 위치라도 다른 면·부위·환자 좌우의 혈자리를 섞어 확정하지 않는다. 보이지 않는 면의 위치는 별도 검수한다.
4. 후보를 선택한 것만으로 시술 시행 완료가 되지 않는다. 침·약침 등 선택 중인 시술에만 기록한다.

정확한 경혈 좌표 검수와 이 선택 기능의 사용성 검수는 별도다. Atlas 검수 화면 승인만으로 모든 후보의 임상 위치가 확정된 것으로 처리하지 않는다.
