# 한방 시술 차팅 목록

정리일: 2026-10-09 (KST)

사용자가 제공한 시그마차트 화면 5장을 기준으로 정리한 HaniSOAP 차팅 참고 목록이다. 시술 목록 → 세부 기법 → 치료 부위·혈자리 순서로 선택하도록 구성한다. 첨부 화면에서 확인한 항목과 화면 밖의 추가 후보를 구분한다. 모든 EMR의 전체 항목을 확인한 목록이나 현재 급여·수가 기준표는 아니다.

## 1. 침술 — 첨부 화면 기준

- 경혈침술
- 안와내침술 (화면 축약명: 안와)
- 비강내침술 (비강)
- 복강내침술 (복강)
- 관절내침술 (관절)
- 척추간침술 (척추)
- 투자법침술 (투자)
- 침전기자극술 (전침)

### 침술 세부 기법 — 첨부 화면의 선택 항목

- 경혈
- 자락
- 도침
- 산침
- 오행
- 사암
- 체질
- 화침
- 온침

시술명과 세부 기법은 별도 필드로 관리한다. 예를 들어 경혈침술을 선택한 뒤 사암 등의 기법을 기록한다. 화면에서는 기법 하나를 선택하도록 되어 있지만, HaniSOAP의 병행 기법 기록 여부는 별도로 결정한다.

## 2. 뜸·구술 — 첨부 화면 기준

- 직접애주구
- 간접애주구
- 반흔구
- 기기구술

## 3. 부항 — 첨부 화면 기준

- 자락관법
- 자락관법 2부위
- 유관법
- 부항컵 수량 선택

부항컵 수량은 시술 종류와 별도로 기록한다. 자락관법 2부위는 시술 방식과 부위 수를 함께 나타내는 화면 항목이다.

## 4. 온열·한냉·물리요법 — 첨부 화면 기준

- 경피경근온열요법 (화면: 경피경근온열)
- 경피적외선조사요법 (경피적외선조사)
- 경피경근한냉요법 (경피경근한냉)
- 물리요법 (세부 치료를 선택하는 메뉴)

## 5. 추나 — 첨부 화면 기준

- 단순추나
- 복잡추나
- 복잡추나80
- 특수추나

복잡추나80은 화면의 청구 구분명으로 보존한다. 별도 시술 기법으로 분류하지 않으며, 복잡추나의 청구 구분으로 관리한다.

## 6. 약침·한약 — 첨부 화면 기준

- 약침
- 한약
- 보험약
- 제약회사·제품 선택

약침은 시술명과 실제 사용하는 약침명을 분리한다. 한약은 처방명·제품명·제형·용량·횟수·일수를 별도로 기록한다.

## 7. 치료 부위·혈자리

첨부 화면의 부위 분류:

- 두경부
- 흉복부
- 요배부
- 상지부
- 하지부

첨부 화면에서 개별 혈명과 코드 선택을 확인했다. 혈자리 목록은 스크롤 일부만 보이므로 전체 경혈 목록으로 간주하지 않는다.

차팅용 추가 필드:

- 좌측 / 우측 / 양측 / 정중선·좌우 해당 없음
- 개별 혈자리: 혈명＋코드＋좌우
- 투자법: 시작 혈자리＋도달 혈자리

좌우 구분은 첨부 화면에서 확인한 메뉴가 아니라 HaniSOAP 차팅용 추가 항목이다.

## 8. 투자법 혈자리 선택 — 첨부 화면 목록

| 부위 | 혈자리 쌍 |
| --- | --- |
| 두경부 | 풍부–풍지, 지창–협거, 관료–영향, 관료–동자료, 동자료–어요, 인당–찬죽, 사죽공–솔곡, 솔곡–태양, 이문–청궁 |
| 상지부 | 견료–극천, 합곡–후계, 곡지–척택, 내관–외관, 곡지–수삼리, 간사–지구, 열결–태연, 액문–양지, 노궁–합곡 |
| 하지부 | 슬관–슬안, 양릉천–음릉천, 삼음교–현종, 곤륜–태계 |

화면에 표시된 선택 목록의 전사이며, 치료 권고나 자동 선택 규칙이 아니다.

## 9. 추가 등록 후보 — 첨부 화면 밖의 항목

병원에서 실제 사용하는 항목만 활성화한다. 아래 항목이 첨부 EMR의 기본 제공 항목이라는 뜻은 아니다.

| 분류 | 추가 목록 |
| --- | --- |
| 침술 | 전자침술, 레이저침술, 분구침술, 이침, 두침, 수지침, 피내침, 피부침, 매선 |
| 부항 세부 방식 | 주관법, 섬관법, 화관법 |
| 전기치료 | 경피전기자극요법(TENS), 간섭파 치료(ICT) |
| 기타 물리요법 | 치료용 초음파, 저출력 레이저, 파라핀욕, 견인치료, 운동치료, 테이핑, 훈세요법·훈증, 극초단파 치료 |

전자침술과 침전기자극술은 별도 항목으로 관리한다. 레이저침술과 일반 레이저 치료도 적용 방식을 구분한다. 이침·두침·수지침 등은 상세 시술 방식으로 두며 각각을 독립 청구 코드로 간주하지 않는다.

## 10. 검사·진찰·행정 — 시술과 별도 관리

첨부 화면에서 확인한 항목:

- 양도락검사
- 검사 메뉴
- 변증기술료
- 초진·재진·공휴일 구분
- 서류
- 기타

## 11. 차팅 데이터 구성

시술 종류 → 세부 기법 → 부위·좌우·혈자리 → 도구·약제 → 수량·시간·설정 → 시술 후 반응

- 침술: 시술명, 기법, 부위·좌우, 혈자리, 침 규격·개수, 유침시간
- 전침: 부위·혈자리, 주파수·모드·시간, 환자 반응
- 뜸: 종류, 부위·혈자리, 수량·시간, 피부 반응
- 부항: 방식, 부위·좌우, 컵 수, 유지시간
- 약침: 약침명·농도, 부위·좌우, 부위별 용량·총량, 환자 반응
- 추나: 종류, 부위·분절, 적용 기법, 시행시간, 반응
- 물리요법: 치료명, 장비명, 부위·좌우, 시간·설정

차팅 항목과 청구 항목은 별도로 연결한다. 음성에서 감지한 시술은 후보로 표시하며, 실제 시행 여부와 혈자리·수량·시간은 한의사가 확인한다. 발화나 입력에 없는 세부값을 자동으로 채우지 않는다.
