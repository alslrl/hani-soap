# 경혈·아시혈·압통점 기록

결정일: 2026-10-09 (KST)
상태: 개발 요구사항. 앱 구현 완료를 의미하지 않는다.

## 도해 기준

최신 구현 계획의 기본 후보는 chino-meds의 앞·뒤 SVG와 해당 좌표다. 실제 채택 파일·사용 조건·위치·좌우 검수는 완료 여부를 따로 확인한다. 이전에 만든 로컬 AcuAtlas 그림은 현재 개발 기준이 아니며, 일부 점이 몸 밖에 나타나는 문제가 있어 기본 좌표로 사용하지 않는다. Atlas의 사용 보류가 chino-meds 좌표에도 같은 오류가 있다는 뜻은 아니다.

## 입력 흐름

인체에 위치를 표시한 뒤 경혈 선택 / 아시혈로 기록 / 압통점으로 기록을 제공한다. 경혈은 혈명·코드를 선택하고, 아시혈·압통점은 표시 위치·부위·환자 기준 좌우·설명을 입력한다. 경혈 코드 없이 저장할 수 있어야 하며, 같은 시술에서 경혈과 아시혈을 함께 사용해도 된다.

별도의 아시혈·압통점 추가 버튼도 제공한다. 일반 필기·동그라미를 자동으로 치료점으로 확정하지 않고 사용자가 유형을 선택·확인한다. 도해를 사용할 수 없으면 부위·좌우·설명으로 수기 기록할 수 있다.

## 저장 내용

- 위치 유형: 경혈 / 아시혈 / 압통점
- 부위, 환자 기준 좌우, 점 또는 영역, 도해 뷰·버전·원본 기준 좌표
- 구조물명·위치 설명: 외측 발목, 전거비인대 부위 등 사용자가 확인한 내용
- 경혈 코드: 경혈 선택 때 저장하고 아시혈·압통점은 null 허용
- 관찰 소견: 압통 여부·촉진 반응과 출처
- 시술 종류·실제 시행 여부, 연결한 관찰 위치

아시혈에 가장 가까운 경혈 코드를 자동 부여하지 않는다. 압통점을 트리거포인트·발통점 진단으로 자동 변환하지 않는다. 직접 찍은 점은 도해상의 위치 메모이며 실제 인체의 정확한 위치를 자동 확정하는 자료가 아니다.

## 관찰과 시술 구분

가상 예시:

> O: 우측 외측 발목 전거비인대 부위 압통 확인.
>
> P: 해당 부위 아시혈에 침 치료 시행.

P는 실제 시행을 의료진이 확인한 때에만 생성한다. 압통점만 관찰한 경우 시술 시행으로 처리하지 않는다. 관찰한 압통점에 시술했으면 같은 위치를 연결하고 소견·시술은 구분해 저장한다.

## 보존 및 검증

- 침·약침의 위치 기록은 독립 저장하고 시술 전환 시 복원한다.
- 경혈을 하나도 선택하지 않아도 아시혈·압통점 기록이 저장된다.
- 경혈과 아시혈 혼합, 여러 점, 좌우별 위치·설명을 보존한다.
- 다음 방문에는 지난 위치를 참고로 표시하며 오늘 소견·시행을 자동 복사하지 않는다.
- 채택 도해에서 앞뒤 전환·확대·회전·환자 기준 좌우가 맞는지 별도 검수한다.
- 후보 표시와 실제 시행 확인은 구분한다.
