# 유지관리 계획

갱신일: 2026-10-21. 한의원의 차팅과 진료 기록 업무를 줄이는 초기 오픈소스 프로토타입을 관리하기 위한 기준입니다. 사용자 수·임상 효과·출시일·응답 SLA·정기 실행 시간을 확정한 계획은 아닙니다.

## 이번 공개 정리

- 로그·원음·전사·노션·발표/검수 PDF·외부 제품 스크린샷 등 32개 파일을 먼저 현재 트리에서 제외했습니다. 이후 승인된 이력 재작성으로 원격 브랜치 3개의 과거 버전도 제외하는 공개 사본을 만들었습니다.
- 비공개 전체 이력 bundle, 원격 참조 목록과 변경 맵을 보존했습니다. 공개 저장소에는 원본 백업 참조를 만들지 않습니다. 기존 커밋 주소 변경과 GitHub 캐시·외부 clone의 한계는 [이력 관리](publication-safety.md)를 확인하세요.
- 자체 코드의 MIT와 외부 자료의 CC·공공데이터 조건을 구분했습니다. 남성 피부 모델의 SA 조건과 여성형·원본 도해의 BY 조건을 보존합니다.
- 변증명은 이용조건을 확인한 KTKP 명칭 624행·573종으로 정리했습니다. 미확인 PDF·지침 출처를 제외하면서 고유 명칭이 21개 줄었습니다. 처방명 11,123종과 361종 혈자리 카탈로그는 유지합니다.
- 복제된 한국어/WHO 계열 위치 설명은 제외하고 AcuAtlas 자체 영문 설명과 외부 참고 링크를 사용합니다. 실제 앱의 남녀 도해 참고점 배열은 기존과 같음을 확인했습니다.
- 비공개 근거 50개의 출처 ID·직접 인용을 가리고, 근거를 가린 상태에서 임의 인용을 추가하면 검증기가 거절하도록 보완했습니다.
- 루트와 중첩 README는 영어를 위에, 한국어를 아래에 두었습니다. 새로운 README에도 같은 구성을 기본으로 사용합니다.

## 개발·기여 기준

변경에는 목적·영향 범위·실행한 검사·미검증 항목을 남깁니다. 공개 파일 검사, 타입 검사, 단위 검사, 서버 검사와 데이터 파생 일치 검사를 우선 실행합니다. DB·E2E·실기기·실제 모델·외부 발송은 격리된 환경과 별도 권한 아래 확인하며, 다른 검사의 통과로 대체하지 않습니다.

새 명칭·도해·데이터를 추가할 때는 원천 조건과 실제 취득 경로를 구분합니다. 공개 웹페이지라는 이유로 재배포 허락을 가정하지 않고, 원천에서 허용한 명칭과 중간 제공자의 창작 해설문·UI를 구분합니다. 명칭·좌표 데이터의 일치는 임상 정확성·처방 적합성의 검증이 아닙니다.

## 진료 기록과 보안

입력 변경 후 오래된 SOAP 승인, 원문 근거 누락, 의료진 확인 상태, 환자·방문 경계, 동시 수정, 발송 중복의 회귀 검사를 유지합니다. AI 초안이 의료진 확인 없이 확정 기록이나 환자 발송으로 바뀌지 않도록 합니다.

실환자 도입 전에는 동의·최소 수집·보존 및 삭제·감사 기록·계정별 권한·임상 검증을 별도로 설계하고 검토해야 합니다. 현재 프로토타입을 실환자용 검증 완료 제품으로 설명하지 않습니다.

## 이슈와 릴리스

이슈는 버그·개선·보안·권리 확인으로 분류하고 실제 환자 자료·인증정보가 없는지 먼저 확인합니다. PR은 테스트·라이선스·데이터 영향·롤백 방법을 검토한 뒤 유지관리자가 병합합니다. 공개 릴리스에는 변경 기록과 실제 확인한 검사 범위를 남깁니다.

정기 점검에서는 이슈, 의존성 보안 업데이트, 검사 실패, 외부 자료 조건 변경을 확인합니다. 이번 문서 추가만으로 자동 루틴이나 보안 제보 기능이 활성화되지는 않습니다. 비공개 제보 설정·CI·별도 운영 자동화는 실제 설정과 검증을 거쳐야 합니다.

## Codex 활용

이슈 재현, 작은 수정과 회귀 테스트, PR 검토 보조, 의존성 갱신, 릴리스 체크리스트와 기술 문서에 활용합니다. 유지관리자가 결과와 권한을 검토한 뒤 병합·배포합니다. 지원 크레딧의 용도는 오픈소스 유지관리 작업을 중심으로 설명하고 진료 전사 서비스 운영비와 혼동하지 않습니다.
