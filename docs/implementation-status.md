# 구현과 검증 상태

2026년 10월 9일 구현 기록입니다. 계획·실제 코드·외부 연결·기기 검증을 구분합니다.

## 구현된 기능

- PC 현황과 진료실: 환자 선택, 과거 승인 기록, SOAP 수정·새 버전 저장·승인, 별도 진료 시작·마침, 근거 대조, EMR 복사.
- PC 음성: 한 번 획득한 마이크 스트림의 전체 녹음과 WebRTC 전사, 입력 레벨, 녹음 이동 유지, 브라우저 청크 복구, 별도 음성 업로드.
- AI: 화자 분리 전사, 출처를 포함한 사전 후보 검색·보정 검토, 근거가 연결된 SOAP 초안, 승인 기록만 사용한 안내와 과거 기록 브리핑, 필기 텍스트 후보.
- iPad: 앞뒤 인체·부위 확대, 체크 패턴 인식, 부위별 경혈 팝업, 아시혈·압통점 설명, 시술별 독립 표시·필기, 초안과 시행 확인, PC 후보·시술 동기화.
- 재진·후속 관리: 12개 질문과 세부 답변, 직접 확인한 수치만 저장, 같은 조건별 경과 그래프, 안내 승인·모의 발송·응답, 불편 응답의 연락 작업과 처리 기록.
- 서버: PIN 세션, Origin 검사, 요청 상한, 버전 충돌 검사, 원문·승인 기록 보존, 로컬 및 Supabase 저장 어댑터, 비공개 음성 업로드, Vercel Workflow.

## 확인한 결과

- Next.js 프로덕션 빌드와 TypeScript 검사 통과.
- 로컬 PostgreSQL 격리 환경에서 migration·seed·정규 테이블·RLS·권한·버전 충돌·동시 저장·롤백·요청 상한 검사 통과.
- HaniSOAP 전용 Supabase 프로젝트 생성, migration 적용, 가상 환자 2명·방문 6회 seed 주입과 원격 DB lint 통과.
- 실제 음성 25초 구간으로 전사 모델 호출, SOAP Structured Output 및 인용 구간 검증, 사전 보정 모델 호출 통과.
- 실제 안내 초안 생성에서 승인 P의 근거 대조와 검토 전 초안 저장 확인.

브라우저 전체 흐름·실시간 음성 연결·배포 후 검증 결과는 통합 검증 완료 뒤 이 문서에 기록합니다.
