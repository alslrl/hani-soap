# 전사 처리 개요

공개 코드 기준 처리 버전은 `src/lib/ai/transcription-alignment.ts`의 `dual-asr-v2.1`입니다. 진료 원음·원문 전사와 당시 실제 사례별 비교 보고서는 공개 파일에서 제외했습니다. 이 문서는 처리 구조만 설명하며 전사 정확도나 임상 성능의 수치를 주장하지 않습니다.

## 두 경로의 결과를 보존합니다

파일 본문 전사와 화자·시간 구간 전사를 따로 받아 연결합니다. 원문 두 결과와 대응 관계를 보존하며, 근거가 부족한 화자나 짧고 반복되는 발화는 임의로 확정하지 않습니다. 입력 변경·실패·재시도와 검토 필요 상태는 기록에 남깁니다.

대응이 불확실하거나 누락된 부분은 제한된 원음 구간을 다시 전사해 비교할 수 있습니다. 실제 모델 호출은 비용과 원음 전송을 수반하므로 가상 음성·승인된 테스트 환경에서만 검증합니다. 부분 재전사 결과가 충돌하면 자동으로 확정하지 않습니다.

## 개인정보 처리와 검토 한계

후속 텍스트 AI 요청에는 식별정보 가림을 적용하지만, 음성 자체의 발화 내용이 지워지는 것은 아닙니다. 파일 정규화나 메타데이터 제거도 음성 비식별화를 뜻하지 않습니다. [텍스트 처리 범위](text-privacy.md)를 확인하세요.

화자 역할·용어 보정·SOAP 초안은 의료진의 검토 대상입니다. 전사 누락·수치·좌우·시행 여부가 기록을 왜곡하지 않는지 확인해야 합니다. 합성 테스트의 통과를 실제 진료 음성·iPad·외부 서비스의 검증 완료로 확대하지 않습니다.

## 관련 파일

- `src/lib/ai/transcription-alignment.ts`: 본문과 화자·시간 구간 대응
- `src/lib/ai/transcription-refinement.ts`: 대응 검토와 부분 재전사 결과 반영
- `src/lib/ai/__fixtures__/dual-transcription.json`: 합성 음성 기반 테스트 결과이며 실제 환자 자료가 아닙니다.
