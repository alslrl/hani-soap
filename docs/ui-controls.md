# 공통 선택 메뉴와 펼침 표시

`AppSelect`는 마이크·화자 역할·전사 버전·후속 관리·재진 질문·시술 위치의 선택 메뉴를 공통 디자인으로 표시한다. Radix Select 2.3.8을 사용하며 앱의 흰색·회색·검정 스타일을 유지한다. 방향키·Home/End·타이핑 검색·Escape·바깥 클릭과 포커스 복귀를 지원한다. 메뉴는 화면 여백 안에서 배치하고 터치 환경에는 44px 이상의 항목 높이를 적용한다.

기존 `<option>` 목록과 `value`를 그대로 전달하며, 값 변경 콜백은 `event.target.value`와 `event.currentTarget.value`를 제공한다. 실제 React DOM change 이벤트 전체를 흉내 내지 않는다. 기존 화면이 사용하던 값 변경·미저장 변경 확인·기록 저장 로직은 유지한다. 빈 값과 숫자 0을 구분하고, 선택할 수 없는 컨트롤·항목은 비활성 상태를 전달한다.

`Disclosure`는 실제 `<details>`와 `<summary>`를 사용한다. 기존 `onToggle`, 열린 상태, 자료 조회 동작을 유지하고 브라우저 삼각형과 개별 플러스 표시를 공통 꺾쇠로 대체한다. 아이패드 선택 메뉴에서 Escape를 누르면 메뉴가 먼저 닫히며 바깥 시트는 유지한다.

`ActionArrow`는 이동 링크·버튼의 문자 화살표를 기존 Lucide 아이콘과 같은 SVG로 표시한다. 장식 아이콘은 스크린리더의 버튼 이름에 포함하지 않는다.

스타일은 `src/components/ui/controls.css`에 모으고 앱 루트에서 불러온다. 새 화면에서도 같은 컴포넌트를 사용한다. 자주 사용하는 업무 컨트롤에는 열림 애니메이션을 추가하지 않았다.

검증: TypeScript·프로덕션 빌드, 마이크 키보드/외부 클릭/선택/펼침 표시, 터치 iPad 메뉴 경계·Escape·포커스 복귀, 기존 화자 그룹/개별 수정과 전사 저장 요청, 후속 관리 모의 응답, 시술 좌우와 시술별 선택 저장 흐름을 격리된 로컬 데이터로 확인했다. 실제 마이크·AI·카카오 전송이나 운영 데이터 변경은 수행하지 않았다.

현재 수정은 독립 작업본이며 운영 배포 여부와 구분한다.
