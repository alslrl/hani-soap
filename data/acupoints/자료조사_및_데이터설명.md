# 아이패드 혈자리 선택용 자료 조사

조사일: 2026-10-09

## 추천 조합

화면에서 지역을 선택하고 가까운 경혈을 찾는 바탕은 **AcuAtlas의 4개 인체 도해 + 정규화 좌표**가 가장 직접적으로 맞는다. 한글 혈명과 소속 경맥은 **KMCRIC 14경맥 목록**으로 대조했고, 한글 위치 설명은 **KM-Agent의 공개 연구 CSV**를 연구 준비 자료로 연결했다. 실제 사람에서 확인하는 참고자료는 **KMCRIC 취혈 영상**이다.

이번 산출물은 자료 조사와 데이터 준비 결과다. 361개 임상 위치를 한의사가 모두 검토한 자료, 완성된 아이패드 앱, 청구 기준 매핑 결과는 아니다.

AcuAtlas의 도해는 간단한 선 인체 모형이다. 상세 해부도·초음파 사진이나 실측 좌표로 이해하면 안 된다. 실제 촬영 자료가 필요하면 KMCRIC 영상 제작 협의 또는 별도 동의받은 촬영이 필요하다.

## 저장한 파일

- `경혈_361_위치좌표.json`: 코드, 한글/한자 이름, 경맥, 한영 위치 설명, 부위 분류 초안, view/x/y, 도해 파일, 원출처.
- `경혈명_361.txt`: 코드 / 한글 혈명 / 한자 / 경맥을 한 줄씩 정리.
- `경외기혈_48_위치.json`: 경외기혈 48종. 기존 361종과 구분; 이번에 수집한 화면 좌표는 없음.
- `표면해부학_이침참고_7.json`: 원자료의 7개 참고 항목. 이들을 독립 혈자리 7개라고 집계하지 않음.
- `figures/anterior.png`, `posterior.png`, `lateral.png`, `head.png`: 공개 원본 도해. 모두 900×1600, 검은 선과 투명 배경이므로 밝은 바탕 위에 표시할 것.
- `경혈좌표_미리보기.png`: 원본 도해에 수집 좌표를 점으로 표시한 검토용 미리보기. 임상 정확성 심사를 통과한 위치표는 아님.
- `도해_출처.json`: 그림 파일의 원본 URL, 크기, 해시, 라이선스.
- `검증기록.json`: 코드/명칭 대조, 한자 보정 15개, 좌표 범위 및 알려진 제한.

## 데이터 검증 결과

- 표준 혈자리 361종의 코드가 KMCRIC 경맥별 목록과 모두 연결됨.
- JSON의 중복 코드 없음; x/y 모두 0~1 범위.
- 앞면 170, 뒷면 97, 옆면 50, 머리 44로 총 361개. 이는 출처가 각 혈자리를 배치한 대표 뷰별 수다.
- AcuAtlas의 간경 코드 LV를 이 프로젝트에서는 LR로 통일하고 원본 ID도 보존함.
- 연구 CSV의 열결·협거·불용 등 한자 일부 누락 15개를 KMCRIC 목록으로 보정. 변경 기록 보존.
- 원본 416행을 모두 혈자리 416종으로 보지 않고 361/48/7로 구분.
- 도해 위 점의 렌더링은 확인했지만 각 점의 취혈 정확성·손발 확대 화면·좌우 전체 인스턴스는 미검토.

## 두 단계 선택에 연결하는 방법

1. 앞면 / 뒷면 / 옆면 / 머리 화면을 선택한다. 손·발·귀는 확대 화면을 따로 마련하는 편이 좋다.
2. 터치나 펜으로 선택한 화면 위치를 그림 기준 0~1 좌표로 바꾼다. 확대/이동 및 여백을 뺀 실제 그림 내부 좌표를 써야 한다.
3. 같은 view의 점 중 선택 원/영역 안에 있는 후보를 찾는다. 후보가 없거나 적으면 같은 부위와 인접 부위로 넓힌다. 시술자가 선택해 확정하는 구조로 둔다.
4. 거리 순으로 정렬한 후보에서 즐겨찾기를 위에 올린다. 픽셀 거리와 인체의 실제 거리/촌수는 같은 것이 아니다.
5. 확정 기록에는 `point_code`, `side(left/right/midline)`, `procedure_type`, `region`, `visit_id`를 저장한다. 즐겨찾기는 사용자별, 지난 방문 값은 방문 기록별로 저장한다.
6. 경혈 코드, 부위 선택, 시술 기록을 청구 후보 생성의 입력으로 넘긴다. 경혈 코드 자체는 보험 수가/청구 코드가 아니므로 청구 규칙 데이터와 별도 매핑해야 한다.

양측 혈자리는 현재 도해에서 한쪽만 표시된다. 361은 혈자리 종류 수이며 좌/우 시술 위치를 모두 세어 놓은 목록이 아니다. 앞/뒤는 반전으로 상대 쪽 후보를 제시할 수 있지만, 임상 좌우 표기와 화면 좌우를 구별하고 확대 화면에서 확인해야 한다. 옆면은 좌/우 뷰를 따로 관리해야 한다.

## 모델에 필요한 추가 작업

- 좌/우 인스턴스 및 앞/뒤/옆/머리/손/발 확대 뷰 좌표를 전문 검토하여 확정.
- 도해상의 부위 영역(polygon)과 손가락/펜 선택 반경을 정함. 이번 body_region_hint는 위치 설명 첫 구절에서 추출한 분류 초안이다.
- 한글 위치 설명의 상용 재배포 권리범위 확인; 필요하면 표준의 사실관계를 기준으로 자체 한글 설명을 다시 작성.
- 근육/압통점/척추 레벨 필기는 별도의 사용자 메모로 저장하고, 경혈 선택값과 분리. AI 정리 결과는 확인 후 임상 메모에 반영.
- 경혈 목록과 시술 종류, 청구 규칙을 별도 테이블로 관리.
