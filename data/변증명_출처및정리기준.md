## 재현 기준

정리 전 변증명_출처기록.json의 기록 배열에서 자료원이 정확히 'KTKP 용어사전(의방성도 공개 스냅샷)'인 행만 순서대로 남긴다. 보존한 행의 변증명, 한자, 출처종류, 자료원, 자료번호, 출처URL은 변경하지 않는다. 출처URL은 실제 취득 경로인 스냅샷 URL을 유지하며 원천 API URL로 덮어쓰지 않는다. 개인 컴퓨터의 파일 경로는 제외된 PDF 행과 함께 제거했다.

두 텍스트 목록은 현재 JSON으로 아래와 같이 재생성할 수 있다. 추가 명칭 생성, 의미상 병합, 진단 분류의 보충은 하지 않는다.


```js
const rows = JSON.parse(readFileSync("data/변증명_출처기록.json", "utf8")).기록;
const names = [...new Set(rows.map(row => row.변증명))].sort();
for (const file of ["data/변증명_통합.txt", "data/변증명_온라인.txt"]) {
  writeFileSync(file, names.join("\n") + "\n");
}
```

위 코드는 Node.js에서 readFileSync와 writeFileSync를 node:fs에서 가져와 실행한다. 기록 배열은 624행, names는 573개여야 한다. 이는 보존된 선별 결과로부터 파생 목록을 재현하는 방법이며, 과거의 수작업 선별 판단 전체를 자동 재현한다는 뜻은 아니다.
