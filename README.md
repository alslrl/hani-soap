# HaniSOAP

**진료 중 나눈 대화와 시술 기록을, 환자 안내와 다음 재진까지 연결합니다.**

HaniSOAP은 한의사를 위한 AI 진료 기록·후속 관리 웹앱입니다. 진료실 PC에서는 음성을 녹음하고 기록을 검토하며, iPad에서는 인체 도해에 시술 부위와 메모를 남깁니다. 두 화면의 기록은 같은 환자의 같은 방문으로 모입니다.

진료가 끝난 뒤에는 의료진이 확인한 기록을 바탕으로 환자 안내를 만들고, 이후 응답과 증상 변화를 다음 진료에서 이어서 확인할 수 있습니다.

## 주요 기능

### 대화에서 진료 기록으로

PC에서 녹음을 한 번 시작하면 전체 녹음과 실시간 전사를 함께 처리합니다. iPad에서 별도로 녹음할 필요가 없으며, 미리 준비한 음성 파일을 업로드해 사용할 수도 있습니다.

전사 결과에서는 한의학 용어 사전에 기반한 보정 후보를 원문과 비교해 선택할 수 있습니다. AI는 전사를 바탕으로 SOAP 형식의 기록 초안을 만들고, 의료진은 각 내용의 근거를 확인하며 수정·승인합니다. SOAP은 환자의 호소, 관찰·검사 내용, 평가, 치료 계획을 나누어 정리하는 방식입니다.

### iPad에서 바로 남기는 시술 기록

세로 화면 상단에서 환자 정보를 확인하고, 크게 표시된 앞·뒤 인체 도해에 시술 부위와 필기를 남깁니다. 부위를 체크하면 해당 영역의 경혈 후보가 나타나며, 필요한 혈자리를 선택하거나 아시혈·압통점을 기록할 수 있습니다.

침·도침·약침·뜸·부항의 표시와 필기는 각각 관리됩니다. 시술 종류를 바꾸면 해당 시술의 기록을 보고 입력할 수 있습니다. 손글씨는 원본과 함께 보존하며, 텍스트 추출 결과를 확인한 뒤 저장합니다. 시술 계획과 실제 시행 여부도 구분해 기록합니다.

### 승인한 기록으로 만드는 환자 안내

의료진이 승인한 진료 기록을 바탕으로 생활 관리와 주의사항 등의 안내 초안을 만듭니다. 안내 내용을 검토한 뒤 발송 단계로 넘기고, 환자의 응답과 필요한 연락 작업을 함께 관리합니다.

### 이전 방문을 이어 보는 재진 화면

다음 방문에서는 과거 승인 기록의 요약과 근거를 확인하고, 이번에 물어볼 내용을 정리할 수 있습니다. 방문별 기록과 직접 확인한 증상 수치를 모아, 같은 측정 조건의 경과를 그래프로 비교합니다.

## 사용 흐름

1. **환자와 방문 선택** — 오늘의 대기·진료 중·진료 완료 환자를 확인하고 진료실을 엽니다.
2. **대화와 시술 기록** — PC에서 녹음하거나 음성을 업로드하고, iPad에서 시술 부위와 메모를 남깁니다.
3. **진료 기록 검토** — 전사와 용어 보정 후보를 확인하고, 근거가 연결된 SOAP 초안을 수정·승인합니다.
4. **환자 안내 준비** — 승인 기록을 바탕으로 만든 안내를 검토합니다.
5. **후속 관리** — 안내 이후 응답을 확인하고, 필요한 연락과 처리 내용을 남깁니다.
6. **다음 재진** — 지난 기록과 증상 변화를 확인하며 새 방문의 진료를 이어갑니다.

## AI는 초안을 만들고, 의료진이 확정합니다

AI가 생성한 전사 보정, 진료 기록, 환자 안내와 필기 추출 결과는 검토 대상입니다. 전사 원문과 이전 기록을 보존하고, 의료진이 확인한 내용을 승인 기록으로 남깁니다. 환자 안내와 재진 브리핑에는 승인된 진료 기록을 사용합니다.

## 데모 범위

현재는 발목 염좌와 소아 야뇨 두 사례를 중심으로 진료부터 재진까지의 흐름을 시연하는 프로토타입입니다. 데모 환자의 프로필과 진료 이력은 가상 데이터입니다.

- **환자 안내·응답:** 모의 발송과 모의 응답으로 후속 관리 흐름을 보여줍니다. 실제 카카오 발송은 아직 연결하지 않았습니다.
- **EMR 연결:** 검토·승인한 기록을 복사해 옮기는 방식입니다. 시그마차트에 직접 기록을 쓰는 연동은 포함하지 않습니다.
- **인체 도해:** 시술 부위와 경혈 후보를 선택하는 작업면입니다. 정밀 경혈 위치를 판정하는 도구로 검증된 상태는 아닙니다.
